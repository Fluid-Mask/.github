## 🧠 Overview

Fluid Mask is a masking tool for cutting objects out of photographs: it traces edges by colour similarity, keeps soft transitions such as hair or foliage, and returns the result as a layer mask in Photoshop or as a transparent PNG.

Published by Vertus. Category: Image masking and cut-out.

The archive in this repository contains the plug-in suite itself plus the integration files for Adobe Photoshop CC 2019 or newer.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| ✂️ Edge Tracing | Marks the object boundary and lets the tool follow the edge by colour similarity instead of a lasso. |
| 🌿 Soft Edge Handling | Keeps hair, fur and foliage detail that hard masks normally cut off. |
| 🧽 Clean-up Brushes | Restores or removes stray areas after the automatic pass without restarting the mask. |
| 🗂️ Multiple Masks | Several objects can be masked in one session and exported separately. |
| 🔁 Reusable Mask | The finished mask returns to Photoshop as an editable layer mask. |
| 📤 Format Export | Saves cut-outs as PSD with alpha, TIFF or PNG with transparency. |
